- [`personal-v1.md`](personal-v1.md) — Personal Product v1 구현 delta 리서치.

- [`ingest.md`](ingest.md) — Ingest 서버·저장 아키텍처와 공개 쓰기 경계.
- [`experiment-fleet.md`](experiment-fleet.md) — Experiment fleet(사전 등록 변형 함대) 리서치와 OSS 관행 조사.
- [`session-replay.md`](session-replay.md) — Session replay 법·규제·기술 리서치와 수집 게이트 원장.

## 규칙

- 원본 자료는 `source/`에 보존한다.
- 주장과 제품 권고를 분리해 기록한다.
- 1차 연구, 공식 제품 문서, 규제기관 지침을 우선한다.
- 커뮤니티 보고와 벤더 마케팅은 낮은 신뢰 근거로 표시한다.
- 반복되는 관행을 검증 없이 보편 임계값으로 바꾸지 않는다.
